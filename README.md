# 🎓 Java University Templates

A comprehensive collection of Java templates organized by topic, from beginner to advanced. Perfect for students, teachers, and developers looking for clean, well-commented examples.
IMPORTANT = Open the files one by one in case you run into problems with the variables

## 📚 Categories

### 🔹 Basics
- `01-basics/04-arrays-and-matrices/` - Arrays and matrices operations

### 🔹 Object-Oriented Programming
- `03-oop/02-inheritance-and-polymorphism/` - Inheritance and polymorphism
- `03-oop/03-polymorphism-and-interfaces/` - Interfaces and polymorphism
- `03-oop/04-encapsulation-and-nested-classes/` - Encapsulation and inner classes

### 🔹 GUI Applications
- `04-gui-applications/01-swing-basics/` - Basic Swing applications
- `04-gui-applications/02-swing-layouts/` - Layout examples

### 🔹 Algorithms
- `05-algorithms/01-searching-algorithms/` - Linear and binary search
- `05-algorithms/02-sorting-algorithms/` - Bubble, Selection, Insertion, Shell, Quick, Merge Sort
- `05-algorithms/03-recursion/` - Recursive algorithms
- `05-algorithms/04-merge-and-combine/` - Array merging

### 🔹 Data Structures
- `06-data-structures/01-queues/` - Queue implementations
- `06-data-structures/02-stacks/` - Stack implementations
- `06-data-structures/03-stacks-and-queues/` - Combined operations
- `06-data-structures/04-lists/` - ArrayList and List operations

### 🔹 File I/O
- `07-file-io/01-text-files/` - Text file operations

## 🛠️ How to Use
1. Clone the repository
2. Navigate to the desired folder
3. Compile with `javac FileName.java`
4. Run with `java FileName`
